Privacy Policy

Last Updated: January 2026

This Privacy Policy describes how the Pinterest Product Publisher application ("the Application") handles information in connection with its use of the Pinterest API.

1. Overview

The Pinterest Product Publisher application is designed to publish product images to an official Pinterest Business account using Pinterest’s authorized API services. The application is used solely for content publishing and traffic generation to our online store.

2. Information We Collect

The Application does not collect, store, process, or sell personal data from end users or Pinterest users.

The only data accessed through the Pinterest API is limited to:

  • Authorized account access tokens
  • Board selection information
  • Product image content provided by the store owner
  • Pin publishing status responses

No personal profile data, email addresses, or private Pinterest user information is accessed or retained.

3. How Information Is Used

Any data accessed via the Pinterest API is used exclusively for:

  • Publishing product images to authorized Pinterest boards
  • Associating pins with product URLs
  • Managing authorized API sessions

The Application does not use collected information for advertising personalization, profiling, or third-party marketing purposes.

4. Data Sharing and Third Parties

The Application does not share, transfer, sell, or disclose data to third parties.

The only third-party service involved is Pinterest itself, through its official API infrastructure.

5. Data Storage and Retention

The Application does not permanently store personal data. Access tokens are securely stored locally for authentication purposes and are not distributed or exposed publicly.

6. Security Measures

We take reasonable technical measures to protect API credentials and prevent unauthorized access. The Application operates in a controlled environment and uses secure HTTPS communication with Pinterest’s API endpoints.
