Privacy Policy

Last Updated: January 2026

Digital Adventure is a private automation tool that uses the official Pinterest API to publish product images with product links to an authorized Pinterest Business account.

1. Purpose of the Application

This application is used exclusively to upload product images that are manually provided by the business owner. Each image is published as a Pin along with a corresponding product URL directing users to our online store.

2. Data Collection

The application does not collect, store, process, or analyze personal data from Pinterest users or visitors.

No user accounts, passwords, emails, analytics data, or personal identifiers are collected.

3. Pinterest API Usage

The application uses Pinterest’s official API solely for:

  • Uploading product images
  • Attaching product destination links
  • Publishing Pins to an authorized board

The application does not access other Pinterest user data or private information.

4. Data Storage

No personal data is stored. API access tokens are stored locally in a secure environment strictly for authentication purposes. These tokens are not shared with third parties.

5. Third-Party Sharing

The application does not sell, share, or distribute any data to third parties. The only external service involved is Pinterest, via its official API infrastructure.

6. Security

Reasonable technical safeguards are applied to protect API credentials and prevent unauthorized access.
